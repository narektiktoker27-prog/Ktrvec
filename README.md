# Railway Python Bot Template

Place your Python file in this folder and rename it to:

your_bot.py

The same Python file should remain runnable in Termux.

If your program needs packages, add them to requirements.txt.

For Telegram bots, store the bot token as the Railway environment variable:

BOT_TOKEN

Do not place secrets directly in source code.

This template is intended for benign bots/apps and does not support covert collection of camera, microphone, GPS, or IP data.
